# Contributing

Contributions are welcome if they keep the system useful for UK job seekers and respect employer/job-board access rules.

1. Open an issue describing a reproducible problem or proposed official API source.
2. Include the official company careers link, ATS provider and board identifier when proposing a new source. Do not submit login credentials.
3. Include unit tests using fictional candidate profiles, salary values and locations.
4. Run `python3 -m unittest discover -s tests -v` and inspect your staged changes before opening a pull request.
5. Keep changes to this public generic engine separate from private candidate configurations.

The project is MIT-licensed; contributions are provided under that licence.
